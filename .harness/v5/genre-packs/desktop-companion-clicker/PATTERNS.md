# 작업 옆에서 오래 함께하는 게임

주요 감정은 Discovery(발견), Expression(취향 표현), Fantasy(성장하는 영웅),
Submission(편안한 반복)이다. 감정은 사람이 확인한다. 자동으로 관측 가능한 동작은
짧은 공격 반응, 발견된 외형, 선택한 빌드, 작업으로 복귀한 간격이다.

## 핵심 패턴

| 패턴 | DesMon 적용 | 관측할 실패 신호 |
|---|---|---|
| 작은 반응은 즉시 | 평소 키/클릭이 영웅 공격으로 보이고 레벨업 뒤 타격량이 증가 | 숫자만 바뀌고 처치 속도/외형 차이를 알 수 없음 |
| 작업을 지속하며 성장 | 동료가 수집된 뒤 자동 공격으로 다음 기회를 준비 | 상시 클릭해야만 정상 진행하거나 알림을 놓치면 손해 |
| 예상 가능한 기회 + 다른 보상 | 환생까지 진행도는 보이고, 3개 외형과 bounded buff roll이 기대를 만듦 | 등장과 보상 모두 예측 불가라 목표를 세울 수 없음 |
| 수집을 통한 표현 | 미수집 외형을 제안하고 50종 이상 도트를 필드/목록에서 보여줌 | 색상 교체만 늘거나 숫자 최고 외형만 사용 |
| 작은 파티 빌드 | 영웅 고정 속성/버프가 단일 속성 vs 혼합 파티 선택에 영향을 줌 | 파티/상대가 바뀌어도 최적 선택이 항상 동일 |
| 거절해도 돌아올 이유 | 마음에 들지 않으면 보류, 짧은 무료 대기 또는 골드 재굴림 | 거절이 리셋/손실/긴 기다림으로 이어짐 |
| 기록이 있는 대결 | PvP 상대 영웅, 배치된 파티, 승패를 목록에서 확인 | 검색어를 모르면 상대를 못 찾거나 실제 전투와 예고가 다름 |

참고 사례로 입력 반응과 수집을 연결하는 [Bongo Cat](https://store.steampowered.com/app/3419430/Bongo_Cat/),
화면 일부에서 자동화 농사를 진행하는 [Rusty's Retirement](https://store.steampowered.com/app/2666510/Rustys_Retirement/),
데스크탑 캐릭터와 상호작용하는 [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/)를 읽는다.
위 DesMon 적용/실패 신호는 해당 작품의 성공률을 주장하는 자료가 아니라 이 프로젝트의 설계 해석이다.

## 안티패턴: 문제 → 증상 → 수정 → 예

1. **지수 체력과 선형 영웅 공격.** 처치 간격이 길어져 영웅 레벨이 무의미해진다.
   실제 5/15/30분 DPS/HP와 영웅 기여도를 측정하고 성장/환생 회복 경로를 조정한다.
   예: `damage=level`, `HP≈10×1.15^index`의 간격을 같은 seed로 전후 비교한다.
2. **가짜 외형 수집.** 최고 외형이 모든 파티에서 숫자까지 우월해 나머지는 버린다.
   외형 단계는 시각적 진화를 담당하고 동료 버프의 범위는 일정하게 유지한다.
   예: 전체 파티 +10–25%와 같은 속성 +20–50%를 파티 구성별로 비교한다.
3. **보류가 벌칙.** 선택이 싫다는 이유로 진행을 잃거나 골드가 필수가 된다.
   수락 전 리셋 금지, 무료 재도전 시간을 짧고 명확하게 유지한다.
   예: 0골드 세이브에서 보류 후 엔진 30초를 진행해 다시 3개를 본다.
4. **재굴림 새로고침.** 창 재개/세이브 재로드가 추가 뽑기를 만들면 골드 선택이 무의미하다.
   pending 선택/roll/cooldown을 저장하고 명시적인 행동에만 RNG를 소비한다.
   예: 같은 세이브 10번 재로드의 제안 ID/roll이 동일한지 검사한다.
5. **작업 방해를 참여로 착각.** 모달/포커스/소리가 잦으면 클릭 수가 높아도 불쾌할 수 있다.
   선택 기회는 확인 가능하게 유지하고 사용자가 열어 보게 한다. 이벤트를 묶어 알린다.
   예: 30분 업무 중 게임 때문에 원래 작업을 중단한 횟수를 사람 관찰로 기록한다.
6. **수집 실패의 침묵.** 가득 찬 도감/동료 슬롯 때문에 보상이 사라져 진행이 무의미하다.
   중복은 기록/유리한 roll 유지, 용량 포화는 명시적 결과를 제공한다.
   예: 모든 외형 보유 상태와 동료 슬롯 최대 상태를 별도 시나리오로 검증한다.

## 참조 게임과 적용 범위

| 작품/공식 소개 | 소개에서 확인되는 구조 | DesMon에서 검토할 해석 |
|---|---|---|
| [Cookie Clicker](https://orteil.dashnet.org/cookieclicker/) | 클릭과 누적 생산 | 일시적인 공격 증가와 다음 영구 성장을 분리해 측정 |
| [Rusty's Retirement](https://store.steampowered.com/app/2666510/Rustys_Retirement/) | 화면 하단 농장, 자동화 로봇, 집중 모드 | 작업 방해 예산을 게임 지표로 취급 |
| [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/) | 창/커서와 반응하는 캐릭터 | 항상 보는 영웅의 형태와 애착을 중요한 보상으로 취급 |
| [Bongo Cat](https://store.steampowered.com/app/3419430/Bongo_Cat/) | 평소 입력과 모자 수집 | 일상 행동이 쌓여 취향을 드러내는 보상으로 연결 |
| [Melvor Idle](https://store.steampowered.com/app/1267910/Melvor_Idle/) | 방치형 기술 성장과 전투 | 적극 입력이 없어도 선택한 성장이 이어지는지 확인 |
| [Chillquarium](https://store.steampowered.com/app/2276930/Chillquarium/) | 물고기 수집/성장/판매 | 다음 발견의 기대와 재화 순환을 함께 관측 |

공식 소개를 바탕으로 한 설계 해석이며, 타 게임의 비공개 전환율/유지율/경제 수치는 추정하지 않는다.
하위 장르별 우선순위는 캐릭터 동반자=존재감/방해 예산, 방치 성장=회복 가능한 성장곡선,
수집 클리커=미수집 기대/유의미한 선택이다. DesMon은 이 세 축을 함께 사용한다.

## 평가 카드

각 축을 `관측`, `문제`, `이번 변경`, `증거`, `미확인`으로 기록한다.

- spawn pacing: 처치 후 다음 적이 바로 이어지는가, 보스 간격에 목표가 있는가.
- reward pacing: 공격 반응/처치/레벨업/포획/환생 보상의 간격은 어떠한가.
- level curve: 영웅 성장이 후반 체력 증가와 동료 DPS 속에서도 느껴지는가.
- idle reward / active reward: 0동료 시작과 동료 보유 방치를 구분했는가.
- rare encounter / surprise: 희귀 결과를 놓쳐도 진행이 막히지 않는가.
- collection / evolution / prestige: 외형 선택이 영구 기록되고 반복 성장에 의미가 있는가.
- daily event: 현재 기능이 필요한가, 시간 강제가 작업 동반자에 맞는가.
- session length: 5/15/30분에 다음 기대가 하나 이상 남는가.
- desktop interruption budget: 자동 포커스 강탈/강제 선택 0을 목표로 했는가.

V5는 조건부 레어 영웅 20종과 몬스터 30종을 구현한다. 시간 조건은 저장되는 활성 플레이
시간으로 도는 월드 주기를 사용해 실제 야간 접속을 강제하지 않는다. 조건 달성/등장/획득을
구분하고, 미등장 외형은 실루엣으로 보인다. 조건과 현재 진행도는 무료로 확인한다.
골드는 영구 훈련, 일시 탐색 개선, 즉시 재굴림에 사용하되 0골드 상태도 모든 콘텐츠를 해금한다.
