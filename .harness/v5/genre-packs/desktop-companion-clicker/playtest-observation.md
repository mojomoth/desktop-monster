# 사람 플레이 관찰 양식

참가자 익명 ID / 소스 지문 / 실행 날짜 / 5·15·30분 / 입력 프로필 / 시작 세이브:

평소 작업을 하며 게임을 곁에 둔다. 플레이 방법을 먼저 설명하지 않고, 도움을 요청하면
설명한 시점과 내용을 남긴다. 실제 업무 문서나 입력 문자를 수집하지 않는다.

| 경과 시간 | 스스로 한 행동 | 직전 화면·보상 | 기대했던 다음 결과 | 관찰자 도움 | 원래 작업 복귀까지 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

5분: 첫 보상을 알아봤는가, 다음 목표를 자기 말로 설명하는가, 최초 선택의 이유는 무엇인가.

15분: 다시 게임을 본 계기, 다른 선택을 고려한 순간, 보류 뒤 복귀 여부,
놓친 보상을 잃었다고 느끼는지 기록한다. 관찰된 확인 횟수와 주목 시간 합계를 남긴다.

30분: 반복 중 새로웠던 점, 의미 없이 반복한 행동, 중단을 원한 시점과 이유,
수집을 계속하고 싶은 구체적 대상을 기록한다. 지속 플레이를 강요하지 않는다.

관찰 사실 / 참가자의 짧은 원문 / 분석자의 추론 / 반대 해석 / 다음 실험을 분리한다.
웃음, 예의상 칭찬, 오래 켜둔 시간만으로 재미나 유지율을 확정하지 않는다.
“더 하고 싶은가”의 답보다 무엇을 다시 보고 싶었는지, 무엇을 기다렸는지 구체적 행동을 확인한다.

최종: 가설별 지지·반증·미확인, 기능 실패, 다음 실험 하나.
