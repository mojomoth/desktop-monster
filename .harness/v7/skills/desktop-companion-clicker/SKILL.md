사용 시 v7 하네스 스킬을 사용한다고 알리고 ../../HARNESS.md와 저장소 AGENTS.md, docs/v0.7/START_PROMPT.md를 읽는다.

현재 단계의 작업을 실행한다. setup는 하네스와 100 seed × 12시간 기준선이다. candidate는 사전등록 후 구현·측정, release는 최종 소스의 실제 Native와 네 역할 결과 감사다.

기존 사용자 변경·v3 포인터·v5 기록을 보존한다. Host와 서로 다른 Designer/Critic/Balance 에이전트로 진행하고 Host가 Playtester를 겸임해 4슬롯을 지킨다. 판단 순서는 Designer → Critic → Balance → Playtester다. Critic은 구현하지 않는다.

실행기 next가 반환한 전체 prompt/template을 전달하고 실제 agent ID와 근거로 submit한다. 사람이 없으면 재미 검증은 PENDING이며 자동 실행 결과를 사람 플레이로 표현하지 않는다.
