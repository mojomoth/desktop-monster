# 에픽 장비 전용 외형

2026-09-18의 후속 요청으로 에픽 무기 32종과 악세사리 24종을 전용 픽셀 도형으로 다시 제작했다. 기본 무기에서 등급 장식만 늘리던 방식 대신 각 에픽의 날·머리·장식 구조를 개별 작성한다. 실제 게임은 기존 16×16 아이콘과 2× 픽셀 배율을 사용한다.

악세사리는 왕관·날개·안구·행성 고리·해골·봉인 두루마리·모래시계·등불·나방·열쇠 달린 마도서 같은 모티프를 사용한다. 반지·목걸이·부적 각각 8개의 에픽 외형을 갖는다. 에픽의 보라색 등급 테두리·이름 색상과 무기 외곽 반짝임은 유지하고, 내부 보석과 재질에 개별 포인트색을 적용한다. 악세사리는 장착 슬롯에 표시되며 영웅 몸체에 추가로 그리지 않는다.

`src/renderer/sprites/epicEquipment.ts`가 전용 도형을 제작하며 `equipment.ts`에서 에픽에만 사용한다. 일반·고급·레어 168종의 아이콘 도형과 팔레트는 변경 전과 정확히 같다. 아이템 ID·이름·가격·능력치·호환 조건·보스 드롭도 유지한다.

장착 검수 과정에서 두 번째 대기 프레임의 머리가 한 픽셀 내려갈 때 무기가 턱을 덮는 문제를 재현했다. 얼굴 보호 영역도 함께 이동하도록 수정했다. 이 합성 수정은 모든 등급에 적용되므로, 하위 등급의 아이콘 불변과 장착 화면의 모든 픽셀 불변을 혼동하지 않는다.

## 검증 근거

이번 실행 기록은 `.agentdoc/v10-epic-art-20260918/journal.json`이다. 원본 소스·아이콘·검증된 이전 설치파일은 같은 실행의 `preservation/`에 보존했다. 새 외형 때문에 달라져야 하는 픽셀 골든 두 개는 기존 기대값과 실패 기록을 남긴 뒤 갱신했으며, 57,960개 장착 화면과 3,840개 피버·KO 합성의 검사 범위를 유지했다.

테스트 1,202개·린트·타입 검사와 smoke·macOS·Windows 패키징이 통과했다. 비에픽 아이콘 불변, 전체 224종 도형 중복, 무기별 다섯 자세·좌우 반전, 손 연결·얼굴·발·클리핑을 검사한다. 실제 Electron 16개 시나리오, 전체 갤러리 150장·7,148개 표본·4개 전체보기, 에픽 전용 양 배경 이미지 6개를 새 패키지에서 검증했다. DMG 마운트·Windows 설치파일 추출 후 전체 앱 동일성과 두 플랫폼의 컴파일 산출물 238개도 확인했다.
