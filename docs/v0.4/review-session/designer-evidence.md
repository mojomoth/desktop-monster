# v0.4 디자인 검토 — 실제 구현 후보

작성 역할: /root/fun_harness (GAME DESIGNER). 이 문서는 설계 분석이다.
사람 플레이나 아직 끝나지 않은 밸런스 시뮬레이션 결과를 주장하지 않는다.

## 확인한 기존 문제

`src/core/formulas.ts`의 기존 `damageForLevel(level)=level`에 비해 몬스터 최대 체력은
`floor(10×1.15^index)`, XP 요구는 `floor(20×1.4^(level−1))`로 늘어난다.
영웅이 레벨업해도 기여도가 떨어질 위험이 있다. 과거 파라미터를 조금만 바꾸는 것으로는
외형 수집이나 파티 선택의 이유를 만들 수 없다.

사용자 요구는 50종 이상 영웅 외형, 환생에서 미리보는 3개 선택, 마음에 들지 않을 때
보류/골드 재굴림, 형태별 고정 속성/동료 버프와 랜덤 수치, 상대 모습을 보며 고르는
PvP 목록과 전적이다. 조건부 희귀 스폰이나 일일 콘텐츠는 필수 요구를 먼저 검증한 뒤 평가한다.

## 비교한 세 방향

| 대안 | 얻는 점 | 비용/잃는 점 |
|---|---|---|
| 선형 수치 조정 | 기존 함수 몇 개만 바꿔 빠르게 체감 속도 개선 | 영웅 외형/빌드/선택이 없어 핵심 요구와 다음 기대가 남음 |
| 외형 전용 스킨 수집 | 취향을 전투 효율과 분리하기 쉽고 50종을 보상으로 만듦 | 속성/동료 버프라는 사용자 요구와 파티 선택 이유를 충족하지 못함 |
| 고정 형태·속성·버프와 제한 랜덤 수치 | 레벨 성장, 외형 수집, 단일/혼합 파티의 선택, PvP 상대 비교가 연결 | 상태 저장/제안 중복 방지/경제 검증이 추가로 필요 |

세 번째를 선택한다. `src/core/hero.ts`에 최소 상태/고정 catalogue/순수 reducer로 구현하고
기존 엔진과 저장/네트워크 경로를 재사용하는 방향이다. 별도 가챠 결제/서버 권한 시스템은 추가하지 않는다.

## 현재 후보와 이유

- 레벨 피해는 `L+max(0,L−2)^2`이며 1/2레벨은 익숙한 시작을 유지하고 10레벨은 74가 된다.
  영혼 배율과 영웅 환생당 +25%가 재시작 후 성장 속도를 보상한다.
- 레벨 12에서 3개 제안. 서로 다른 속성과 최고 해금 단계 포함, 미수집 우선으로 비교할 이유를 만든다.
- 수락 시에만 레벨/XP/현재 적을 초기화하고 동료/골드를 보존한다. 외형 수집과 좋은 중복 roll은 영구 기록한다.
- 10개 계열 × 5단계의 50종 도트. 외형 단계와 버프 예산을 분리해 상위 외형이 무조건 정답이 되는 위험을 줄인다.
- 고정 속성 버프는 일치 동료에 +20–50%, 전체 버프는 모든 동료에 +10–25%.
  동일 전력 5마리 중 일치 동료가 2/3마리일 때 평균 기여가 14%/21%여서 전체 17.5%와 선택이 갈린다.
- 무료 보류는 진행 손실 없이 엔진 30초. 재굴림은 50+25×min(100,환생 횟수) 골드.
  pending 제안/roll과 offerSerial을 저장하여 창 재개/중복 클릭을 무료 뽑기나 중복 지출로 바꾸지 않는다.
- 부모가 전달한 독립 비평의 '성숙 파티가 약 6초 만에 환생 재진입' 문제에 대응해
  성공한 환생 뒤 HERO_REST_MS=120000을 추가했다. 이것은 실제 관측 로그를 받은 비평가가 재확인해야 한다.
  120초는 수락 후 휴식이고 보류 후 30초와 다르다.
- PvP 시작은 상대 영웅/배치된 파티/서버 전적이 있는 목록으로 연결한다.
  이전 데이터에 영웅/명시적 파티가 없을 때의 호환 경로도 비평가가 검사한다.

## 사전 가설과 검증 방법

1. active(초당2회) 새 게임 첫 환생의 p90은 가상 300초 이하. 100개 seed로 실제 엔진을 실행한다.
2. 무료 보류 후 가능 시점은 활성 엔진 30초, 성공 환생 후 다음 환생은 최소 120초.
   이 항목은 단위 테스트와 성숙 동료 시나리오로 검증한다.
3. 제안 내 중복 ID/속성은 0, 최고 해금 단계 포함률은 100%, 모든 roll은 정수10..25.
4. 단일/혼합 파티에서 버프 선택의 최고 결과가 바뀐다. 모든 상대 속성에서 실제 전력/배틀을 비교한다.
5. 5/15/30분 × active/idle/intermittent의 9개 시나리오와 0골드/기존 동료/최대 도감을 기록한다.
6. 사람 관찰에서는 강해진 피해 인지, 3개 외형 비교, 보류 재방문, 의도치 않은 지출,
   작업 중단 횟수, PvP 목록의 정보 이해를 확인한다. 현재 사람 관측은 PENDING이다.

## 검증 상태

하네스 자체 selftest 8개는 통과했다. 합성 보고서 기반 프로토콜 검사이며 이 설계의
재미/밸런스 통과 근거가 아니다. 실제 앱 게이트와 100 seed 엔진 보고서는 통합 담당자가 수집 중이다.
도트 전체의 멋짐, native 포커스/권한, 패키지/배포 검증은 PENDING이다.
