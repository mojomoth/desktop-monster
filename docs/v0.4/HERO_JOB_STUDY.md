# 원본 크기와 자세를 유지한 직업 영웅 3종

2026-09-09. 이전 3종은 기본 영웅의 의상 변형에 머문다는 피드백을 반영했다.
이번 검토 대상은 **백야 검귀·월영 자객·여명 성기사** 3종이다.
사용자가 이 직업 디자인 방향을 승인한 뒤 요청한 후드·투구와 의상·무기 디테일을 반영했다.
후속 요청에 따라 눈동자와 피부색도 직업마다 다르게 적용했다.
이후 사용자가 같은 방식의 50종 제작을 승인했다. 이 세 모습은 각각
`h01`(검사), `h05`(도적), `h09`(수호기사)에 그대로 포함했다.
최종 50종의 구현·검증 기록은 [HERO_REDESIGN.md](HERO_REDESIGN.md)에 있다.

귀검사·도적·성직자 계열을 참고해 DesMon 크기에 맞는 머리·의상·무기를 그렸다.

- 백야 검귀: 정리한 백발 앞머리, 비대칭 교차깃, 귀수의 손목 붕대, 부츠 장식과 청강 장검.
- 월영 자객: 이마와 뺨을 감싸는 보라 후드, 목도리, 대각 가죽 띠와 버클, 등날을 구분한 단검.
- 여명 성기사: 눈이 보이는 금장 투구와 볼가드, 금장 어깨와 판금 예복, 금빛 홈이 있는 성검.

눈동자는 원본 눈 위치의 1픽셀만 바꾸며, 얼굴과 손의 피부색은 같은 팔레트를 쓴다.
각 직업의 눈 색을 장비 색과 공유해 고유 색상 수는 7색으로 유지한다.
성기사의 눈 위 이마판은 밝게 처리해 푸른 눈과 투구 그림자가 붙어 보이지 않도록 했다.

원본 `hero.ts`의 14×14 프레임, 눈·양손 좌표, 두 발의 접지,
대기 2장과 준비→타격→회수 3장, 정수 배율을 유지했다.
머리 모양과 옷의 윤곽은 새로 그렸고, 각 모습은 7색이다.
무기 길이와 폭은 달라도 손잡이 위치와 공격 방향은 유지한다.
후드와 투구의 챙이 각 자세에서 이마 2픽셀을 덮으며 나머지 얼굴·손 피부 좌표는 원본 그대로다.

`heroJobStudies.ts`는 확정된 세 모습의 기준 도트다. 50종 목록이 이 도트를 그대로 참조한다.
이 페이지의 필드도 실제 영웅 목록을 사용한다. 이전 의상 시안과 검증은 기록으로 남겼다.

## 재현과 검증

```sh
node .harness/v4/loop/render-hero-study.mjs --jobs
npm test && npm run lint && npm run typecheck
npm run build
```

44개 테스트 파일, 675개 테스트, ESLint 0경고, 타입 검사와 빌드 통과.
새 테스트는 15프레임의 크기·팔레트·얼굴·손·접지·서로 다른 실루엣과
정수 픽셀 배율·좌우 반전, 자세별 무기 방향을 검증한다.
후속 검증은 장비가 덮는 이마 2픽셀의 위치와 색을 정확히 검사하고,
그 외 모든 원본 얼굴·손 픽셀이 유지되는지 확인한다.
세 피부색·세 눈 색의 구분, 매 프레임 정확히 1개의 눈동자 픽셀과 원본 위치,
외곽선 색 보존 및 대기/공격 팔레트 일치도 검증한다.

브라우저에서 112px 확대와 56px 실제 크기, 400×260 필드, 공격/반전 제어를 확인했다.
독립 시각 리뷰에 따라 자객 단검의 길이를 모든 자세에서 맞추고 얼굴 침범 1픽셀을 수정했다.
성검도 준비·타격·회수 모두 넓은 칼날로 맞췄다. 브라우저 콘솔 오류 없음.
후속 독립 리뷰에서 챙의 면적과 검귀 부츠 장식의 공격 중 연속성을 보완했다.
직업 디자인과 피부·눈 표현까지 승인되어 50종에 확장했다. Electron 실행 검증은 하지 않았다.
