# 원본 영웅에서 발전하는 3종 시안

후속 상태: 아래 시안은 기본 영웅의 의상 변형에 머문다는 피드백을 받았다.
현재 검토 대상은 같은 크기와 공격 자세에 던파 직업 감성을 더한 [새 3종](HERO_JOB_STUDY.md)이다.

2026-09-09. 사용자는 앞서 만든 50종의 크기와 디자인을 반려하고,
처음 영웅에서 발전하는 모습 3개를 먼저 확인하도록 요청했다.
이번 작업은 이 3개 시안까지이며 실제 환생 목록에는 아직 등록하지 않았다.

## 비교

[대기·공격·좌우 반전 미리보기](hero-three-study.html) ·
[원본 + 3종 비교 이미지](hero-three-study.png) · [실제 필드 배율](hero-three-field.png)

- 모험 검사: 원본 초록 튜닉에 가죽 어깨받이와 허리띠.
- 강철 기사: 같은 초록 소매에 강철 어깨 갑옷·흉갑·정강이 보호대.
- 왕실 근위: 같은 얼굴과 갈색 머리에 녹색 망토·금장·강철 부츠.

세 시안 모두 원본 `hero.ts`의 **14×14 크기, 머리와 얼굴 픽셀, 피부·손 위치,
각 자세의 외곽 경계, 발바닥 높이와 머리/피부/초록색**을 유지한다.
장비 도트만 직접 새로 그렸다. 각 시안은 대기 2장·공격 3장, 총 15프레임이다.

## 재현과 확인

```sh
node .harness/v4/loop/render-hero-study.mjs
npm test && npm run lint && npm run typecheck
```

게임의 실제 `createGame` 렌더러에 이 3종만 주입한 검토용 번들로 필드를 비교한다.
주입은 미리보기 생성기에만 있고 실제 카탈로그·저장·속성·버프는 바꾸지 않는다.
확대 배율은 모두 8배, 실제 표시 크기는 모두 4배(56×56), 필드는 400×260이다.

독립 도트 리뷰에서 발견한 왕실 근위의 손 위치와 망토 금색 단 깜빡임을 수정했다.
`heroEvolutionStudies.test.ts`는 3종/15프레임의 크기·얼굴·손·발·원본 색상 보존을 검증한다.

최종 검증: 43개 테스트 파일·672개 테스트, ESLint 0경고, TypeScript 검사와 빌드 통과.
브라우저에서 대기/공격/좌우 반전 제어를 확인했다. 디자인 확정이나 Electron 실행 검증을 의미하지 않는다.
