## 원본 무결성과 선택

8개 모두 지정4파일114/114 테스트 exit0, screening exit1, 별도 structural verify exit0 로그와SHA가 일치한다. 실제 생산 source와 컴파일 progression export의21키가 각 등록 실험과 정확히 일치하며, source/evaluator/compiled archive,프로토콜,보고서,manifest,20개 seed 파일의 hash와 binding을 재검산했다. 각아카이브의 중복/위험 경로가 없고 각 runs는manifest1+seed20개만 포함한다. source tar는root-relative이고 평가digest는.harness/v7와공식protocol만 포함하며 추가보존DESIGN은별도다.

5대조의100개 원본 raw는 Round05의 동일seed·정책·fixture 대조와 정확히 같다. 모든checkpoint에서 골드 유입−지출=잔액, 안전정수와 정확한bigint 피해/파티힘,실제선택ID 개수와 조건부 보고서를 검산했다. 현재 작업트리와 각실험에 보존된source를 혼동하지 않는다.

등록된 순위는 두목표 통과안에만 적용하는 정수100ms tuple(|firstp50−3150|,|h70p50−36000|,firstp90,ID)이다. 통과안0개이므로 passingRanking=[],proposedExperiment=null이며 자동채택하지 않았다. 목표/분모 수정과 검증 데이터 기반 튜닝 없이, 후속 탐색이 필요하면 허용된 탐색근거로 새사전등록부터 진행한다. 이분석은 새수치를 제안하지 않는다.

현재는 탐색 분석완료이며 V05 장기측정 성공/제품출시 검증이 아니다. 최종0.7.0 소스의 등록AC·canonical gates·9정책별100seed×12h,실제단기9개+연속180분active/10분메뉴,네역할audit·smoke·패키지·고레벨서버호환은 별도다. humanChecks=PENDING을 유지한다.
