# Round07 Critic 독립 진단 — 완료 탐색만

실제 `/root/critic`의 읽기 검토다. 완료된 탐색 seed **10001–10020**의 후보 screening 3개와 prefix1153의 full-12h 원본, 아래 소스를 읽고 재집계했다. 새 실험·게임 실행·테스트·빌드·수치 제안·제품/하네스 수정은 하지 않았다. 검증 seed1–100 보고서, 과거 candidate.json, 검증값이 있는 상태 문서는 열람하지 않았다. 이 문서는 향후 Round08 정식 fun 검토나 audit.mjs 결과 감사, 출시 인증을 대신하지 않는다.

## 직접 확인한 결과

- prefix1153의 첫 성공 전체 p50은 **2878.7초**, 90분 이내 **20/20**으로 두 첫 환생 조건을 통과한다. 같은 후보의 screening/full 첫 성공은 seed별 **20/20 동일**하고 full의 firstReady=firstOpen=firstAccepted도20/20 동일하다.
- 12시간 h70 자격은 **8/20**, 미도달12/20으로 **전체 p50=null**이다. 성공자만의 조건부 p50은 **18852.5초**이며 전체 판정으로 사용할 수 없다. 도달8개 중6개는8시간 전,2개만8–12시간이다. 제시8/20·실제 선택0/20은 무료 첫 슬롯 정책에서 별도로 기록된 결과다.
- 12시간에 모든 seed가 영웅 **14–50종**을 선택하여 h70의10종 조건을 충족했다. 미도달12개가 부족한 조건은 모두 **30000처치**다. 첫 성공 통과가 후기 처리량이나 h70 통과를 보장하지 않는다.

각 분위수는 전체20개를 정렬한 `floor((N−1)q)`이며, 아래 활동 수치는 모두 유한한20개다. 마지막 행은 같은 seed의8시간 값에서12시간 값을 뺀 증분이다.

## 후기 분산과 관측 한계

전원2시간부터 명단30명·동료 최대Lv1이며, 관리/훈련/지출은0이다. `engine.ts:248–269`는 정원30에서 새 동료를 교체 보관하지 않고 일반 추첨 성공을 방출로 처리한다. 따라서 이 무관리·외부 전달 없는 정책에서는 초기30명 풀이 유지되는 코드 경로다. 12시간 선택 파티 기본 힘은 **524172–1994160294765507**로 갈린다. 이 큰 분산은 깊은 포획과 명단 정원 경로에 부합하지만, 원본에는30명 각각의 bossIndex/전체 포획·RNG trace가 없어 특정 seed가 어느 깊이의 추첨 때문에 빨라졌다고 확정할 수 없다.

`collection.ts:34–37,70–87`의 동료 힘은 깊이·레벨·별로 계산하고, `hero.ts:125–126,308–315`의 영웅 환생은 누적 영혼·환생 힘과 필드 초기화를 함께 만든다. 강한 동료·환생의 누적 효과를 설명할 수 있는 경로지만, 개별 효과의 기여율은 이 원본만으로 분리할 수 없다.

`measure.mjs:231–232,316–317`의 heroDamage/companionDamage는 **overkill을 포함한 공격 event 누계**다. 8→12h 증분 전체 p50은 각각 **150399675884 / 159565450957**이며 전원 증가한다. 실제 차감HP·DPS로 해석하지 않는다. partyPower도 당시 대상/영웅에 맞춰 선택한 파티의 **기본 힘 합**이므로 작은 checkpoint 변화를 명단 교체로 해석하지 않는다.

8→12h 새 영웅이0인 seed는 **9/20**, 새 처치종0은 **17/20**, 새 포획종0은 **20/20**이다. 빠른 쪽도 환생 반복과 별개로 신규 획득이 소진된다. 12h checkpoint의 전 구간 누적 최대 **seen 기준** 공백은 p50 **9955.6초**, 최악 **27928.6초**다. 이는8→12h 구간만의 공백이나 모든 보상 부재 시간이 아니다.
