다음 탐색 방향은 아직 등록하거나 실행하지 않은 제안이다.

- L17은 20/20이 90분 안에 성공했으나 중앙값 1636.5초로 너무 빨랐다. 먼저 이 조건에서 XP 성장률을 소폭 올려 중앙값을 늦추는 좁은 범위가 타당하다. 예시 1.41/1.42/1.43, 나머지 control-l17 값 유지가 최대 3개 사전등록 후보의 출발점이다. 시간의 단조 변화나 성공 비율 유지가 보장되지는 않는다.
- B의 미도달 seed 10001/10002/10015/10017은 최초 포획을 각각 44.5/34/34.5/45.5초에 마쳤지만 120분에도 Lv17, 총 79킬, 동료 1–3명에 머물렀다. 최초 포획의 부재만으로 이 꼬리를 설명할 수 없다.
