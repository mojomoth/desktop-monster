# Round04 독립 Balance 분석

실제 agent: `/root/balance`. **8개 실험·11개 보고서·220개 원시 실행의 무결성 PASS, 두 목표 동시 통과 후보 0개**다. 세 후보 모두 첫 환생은 통과했지만 마지막 named 단계 h70의 전체 p50이 8시간보다 빨랐다. 등록 tie-break의 적용 대상과 채택 후보는 없다.

원본 실행의 `endedAt` 확인 뒤만 로그·보고서·원시 기록·아카이브를 읽었다. 탐색 seed 10001–10020만 사용했으며, 검증 seed 1–100을 읽거나 새 시뮬레이션·빌드·테스트를 실행하지 않았다. 원본과 중간 분석 스냅샷은 모두 보존했다.

## 근거 무결성과 판단 경계

- 보고서·원시 데이터·seed별 파일·manifest·로그·실행 메타데이터 SHA와 등록된 ID/parameters/content rules/protocol binding을 재계산했다. 각 보고서는 해당 변형의 보존된 실제 source/build/evaluator를 가리킨다.
- 소스 tar의 src/static/package/lock/tsconfig 경로는 root-relative다. evaluator digest는 `.harness/v7/**`와 공식프로토콜만 포함하고, 함께 보존된 DESIGN_DECISIONS.md는 그 digest 범위 밖이다.
- 5개 controls는 Round03의 같은100개 원시 실행과 완전히 같다. 평가기 지문은 새 사전등록 때문에 달라졌으며, 이번 실행 근거를 과거 결과로 대체하지 않았다.
- 세 후보의 screening/full12h 각각20/20가 immutable reference SHA `790e3441e749bc143b5930a4a11e5fbd6757bf22c5e2c2aabaf173f96b8fd278`와 일치했다. 범위는 기록된 첫 사건 시각·첫 성공 선택까지의 콘텐츠 기록·실제 첫 선택 ID/level/action이다. 과거에 기록되지 않은 공격/처치 전체 trace 일치를 주장하지 않는다.
- 각 checkpoint 경제 수지와 안전 정수/BigInt 직렬화, 도감 기록 및 실제 선택 종류 집계를 점검했다. 상세 p10/p50/p90/worst/미도달과 seed별 후반 수치는 JSON에 있다.

후속 탐색을 한다면, 관측된1.040의 과속과 이전1.050의 전체 p50 미도달 사이에서 **10425/10000, 10450/10000, 10475/10000** 세 내부 비율을 새로 사전등록하는 방향을 제안한다. L17/XP1.41/index79 prefix와 모든 콘텐츠·목표는 유지한다. 이는 미등록·미측정 구간 탐색 제안이며 성과 보간이나 성공 보장이 아니다. 실제 seed10020은1040에서12515초,1035에서35324.5초에 h70 자격을 얻었으므로 HP 비율과 개별 성과를 단조 관계로 가정해서는 안 된다.

분석 완료와 제품 출시 검증은 다른 상태다. 채택·검증100seed·9정책 출시 측정·Native/서버 호환/실제 패키지의 최종 인증은 이 분석에 포함되지 않는다. `humanChecks=PENDING`, `productReleaseVerified=false`를 유지한다.
