# Round05 독립 Balance 분석

실제 agent `/root/balance`. **8개 실험·11개 보고서·220개 원시 실행 무결성 PASS**다. 등록된 두 목표를 통과한 후보는10475와10450이며, 사전등록 동률 규칙의1순위는 **candidate-r5-tail10475**다. 이는 Host의 공식 채택과 별도100seed 검증을 위한 제안이며, 이 분석에서 채택·프로토콜 변경·검증 측정은 수행하지 않았다.

모든 원본 `execution.endedAt`을 확인한 뒤만 로그·보고서·runs·아카이브를 읽었다. 탐색 seed10001–10020만 사용했고 검증1–100은 읽지 않았다. 새 제품 실행·빌드·테스트·측정 없이 원본을 검산했다. 새 분석 JSON/MD 외 원본과 중간 스냅샷을 모두 보존했다.

## 근거와 다음 행동

- 모든8실험의 지정4개 테스트 파일에서94/94가 통과한 로그와SHA를 확인했다. source/evaluator/compiled tar·report·manifest·seed별runs·실행로그의hash와20개 매개변수·콘텐츠·공식protocol binding을 독립 재계산했다.
- 5controls의 전체100개 raw는 Round04와 정확히 같다. source tar는root-relative이며 eval digest 밖의 DESIGN_DECISIONS.md도 보존했다. 과거 결과를 새 검증으로 대체하지 않았다.
- 세후보 screening/full12h 각각20/20가 immutable prefix SHA790e3441e749bc143b5930a4a11e5fbd6757bf22c5e2c2aabaf173f96b8fd278와 일치했다. 범위는 기록된 첫7시각·첫 성공까지의content records·실제첫선택ID/level/action이며, 존재하지 않는 전체 공격/처치 trace를 주장하지 않는다.
- checkpoint별 초기coins+income−spent=coins, 안전정수·정확한bigint문자열, 기록/실제선택 종류를 확인했다. 측정 raw의통계와 각지문은현재 작업트리와 혼동하지 않고 해당변형의보존된source/build에 연결한다.

Host는 이 결과에 따라 정확한10475 후보를 공식 채택한 뒤 untouched validation seed1–100×12시간을 실행할 수 있다. 새 검증에서도 firstAccepted 전체p50 45–60분·90분90/100과 h70전체p50 8–12시간을 확인해야 한다. 검증seed로 수치를 튜닝하지 않으며 실패도 그대로 보존한다.

이 분석은 제품 출시 검증이 아니다. 같은대상소스 등록AC·npm test && npm run lint && npm run typecheck, 최종package/lock0.7.0,9정책별100seed×12h,실제단기9개+연속180분active/10분메뉴,4역할audit·smoke·실제패키지·고레벨운영서버호환이 남는다. Native 첫준비 관측minor는최종자연관측전에 수정·새근거를 만들어야 한다. humanChecks=PENDING,productReleaseVerified=false를 유지한다.

[final-analysis.json](final-analysis.json)에 전체통계·원본지문·엄격선택tuple을 보존했다. 모든중간snapshot과분석기JSON도 같은폴더에 남아 있다.
