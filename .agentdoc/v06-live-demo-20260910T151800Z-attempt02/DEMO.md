# v0.6 패키지 실제 플레이 시연

2026-09-10T15:21:52.912Z 시작, 2026-09-10T15:22:11.762Z 종료. 실제 ARM64 패키지 0.6.0에서 격리한 신규 세이브와 합성 입력으로 실행했다. 개인 세이브·전역 입력·운영 네트워크를 사용하지 않았다.

12초/합성 입력 120회 관측에서 Lv1→12, 처치0→31, 골드0→244, 동료0→1. 이후 메뉴 조작 중 동료 자동 공격으로 추가 보상이 생겨 훈련 구매 직전299G, 구매 후224G 및 훈련0→1을 확인했다. 목표 h03 선택, 표시한 발견3개 확인, 앱 프로세스 종료·재시작 후 목표·진행 보존도 확인했다. 9개 검사 성공, 3개 앱 프로세스 exit0, 임시 데이터 정리 완료. 각 앱 시작 때 기존 smoke 입력3개가 별도로 발생한다.
