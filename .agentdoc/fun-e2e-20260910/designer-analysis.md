# DesMon 재미 검토 — Designer

작성: 2026-09-10 · 역할: `/root/designer` · 분석 대상: 현재 작업 폴더의 v0.5.0 소스

이 문서는 업데이트 제안이다. 게임 기능을 변경하지 않았다. 아래의 **코드 관측**, **설계 추론**, **검증 가설**을 구분한다. 100seed 코어 측정과 실제 Electron의 5분 진행 및 기능 검사 결과를 확인해 갱신했다. 사람 참가자는 없으므로 재미·애착·업무 방해의 최종 판단은 미확인이다.

적용 기준: `.agents/skills/desktop-companion-clicker/SKILL.md`, `.harness/v5/AUDIT.md`, `.harness/v5/agents/designer.md`, `genre-packs/desktop-companion-clicker/{PATTERNS.md,brainstorm-variant.md,balance-template.md}`. 기존 V5의 새 콘텐츠 구현 요구는 과거 구현 계약이며 이번 요청은 현행 게임을 분석하는 하네스다. 새 레어·상점·환생 시스템을 다시 만드는 제안은 하지 않는다.

## 현재 판단

DesMon에는 반복을 확장할 재료가 이미 충분하다. 70종 영웅, 135종 몬스터, 무료 환생 보류, 세 후보, 영웅 중첩, 속성 파티, 골드의 세 용도, 조건부 발견이 구현되어 있다. 지금 먼저 검증할 문제는 **작업하는 동안 얻은 좋은 보상이 보존되고, 돌아온 사용자가 달라진 것과 다음 기대를 알 수 있는가**다. 최초 정적 분석에서는 발견 가독성을 먼저 골랐지만, 실제 측정에서 강한 새 동료가 빈번히 방출되는 것을 확인해 보상 보존 실험을 앞으로 올렸다.

입력은 영웅 공격·치명타·피버를 만들고, 처치는 XP/골드/아이템·보스 포획·다음 몬스터로 이어진다. 동료를 모으면 매초 자동 파티가 공격하므로 작업 중에도 진행한다. 영웅 환생은 현재 레벨·깊이를 초기화하고 영구 공격력·외형·동료 버프를 남긴다. 도감은 특정 종 처치·영웅 선택 이력·속성·필드 시간 등으로 다음 발견 자격을 만든다. PvP는 모은 파티의 활용처다.

따라서 핵심 루프는 이미 `Ambient → Surprise → Interaction → Reward → Collection`에 가깝다. 다만 Surprise가 코드 기록에만 남고 화면에서 지나가거나, 수치상 좋은 선택을 사용자가 해석하기 어려우면 플레이 경험은 다시 `입력 → 숫자 → 환생 버튼`으로 축소된다.

의미이벤트는 레벨업·보스 포획·첫 몬스터 발견·영웅 선택을 합친 대리지표다. 이 공백이 곧 지루함은 아니다. damage 기여도 역시 오버킬을 포함한 emitted damage이며, effective HP 제거 비중으로 설명하지 않는다. active30분 영웅 피해 비중 중앙값 약75.49%이므로 D5의 '동료가 영웅을 항상 압도한다'는 강한 주장은 현행 표본에서 지지되지 않는다.

추가된 실제5분 근거 `.agentdoc/fun-e2e-20260910/e2e.json`은 300,035ms 동안 합성 입력583회, 종료 시 Lv.14·47킬·560골드·동료1·환생0을 기록한다. 22개 기능 검사 중21개가 성공했고 D1이 다시 실패했다. 90초에Lv.12지만 대본이 메뉴를 선택하지 않아 환생0이 유지됐다. `e2e.json.screenshots/5m-active.png`를 직접 열어 **REBIRTH READY가 화면에 있음**을 확인했다. 따라서 이 결과로 사용자가 환생 안내를 발견하지 못한다고 추론하지 않는다.

실제5분 타임라인은150초까지 동료0,180초 체크포인트에 동료1이다. 시뮬 free100seed의120초 내 포획은 다른 RNG·입력 타이밍·환생 정책에 일반화할 보장이 아니다. B를 낮은 우선순위로 두되 무환생 정책의 첫 포획 실패 꼬리를 추가 측정해야 한다. 마지막240초부터300초까지 처치47/골드560은 그대로였다. 이는 메뉴 없이 진행하는 정책의 정체 관측이며, 봇의147킬과47킬 차이를 어떤 업데이트의 개선 효과라고 부르지 않는다.

Balance가 같은 seed끼리 다시 계산한 훈련-무료 처치 차이는 p10/p50/p90=+13/+31/+49이며100seed 중98개 상승·2개 하락이다. 재굴림-무료는−24/0/+20이고 평균−0.8이지만 레어 몬스터 발견은 모든seed에서+1–3이다. 따라서 무료가 항상 우월하다거나 재굴림이 무가치하다는 결론은 내리지 않는다.

D1은 확정된 표시 오류이므로 대안 경쟁과 별개로 가장 먼저 고칠 항목이다. A의 발견 연결은 여전히 유효한 후속안이지만 보상 보존을 해결했다고 주장하지 않는다. B의 초반 무료 동료/포획보장은 free100seed에서 실패0이므로 우선순위를 내린다. C는 실제 파티의 지배성이 입증될 때, D는 업무 환경에서 방해가 관측될 때 순서를 올린다. 현재 게임을 자동으로 고치는 승인은 이 문서에 포함되지 않는다.

## Critic에게 넘기는 반례

1. A의 '신규 발견'이 모든 처치마다 반짝이면 발견을 읽게 만드는 대신 시각 소음을 늘린다. 메뉴 열 때 묶어서 보고, 개별 발견 때문에 창을 열지 않아도 손실이 없어야 한다.
2. A의 목표를 '가장 가까운 조건'으로 자동 추천하면 모든 사람이 같은 경로를 밟고 취향이 사라질 수 있다. 목표를 고르지 않아도 기존 플레이가 진행되어야 한다. 선택 변경에 비용·진행 초기화가 없어야 한다.
3. 현재 영웅 버프는 중첩이 장기적으로 계속 증가한다. 이미 많이 키운 한 외형을 계속 선택하는 전략이 일반 미수집 선택보다 압도적인지 공격한다. 수집/발견 목표와 전투 목표를 따로 평가한다.
4. 강한 새 동료는 깊이 기반 전투력이 높다. 희귀·초기 애착 동료를 강화해도 항상 새 동료로 교체하는 것이 정답이면 135종 수집의 전투 의미가 제한된다. 단일 속성 균등 파티만으로 선택이 있다고 통과시키지 않는다.
5. 120초 환생 휴식은 강제 모달을 막지만, 효율 최적화를 위해 매2분 메뉴를 여는 행동을 유도할 수 있다. 방치 정책이 실제로 환생을 자동 수락하는 시뮬레이션이면 사용자의 주의 비용을 숨긴다. 무메뉴 방치와 기회마다 메뉴 조작을 별도 측정한다.
6. 골드를 한푼도 쓰지 않으면 레어 조건의 `goldSpent`를 만족하지 못하는 항목이 있다. 현금 결제 강제와는 다르지만 '0골드에서도 모든 조건 즉시 가능'이라고 표현하면 거짓이다. 무료 플레이에서 골드를 벌어 정상 지출로 조건을 달성하는 경로를 설명해야 한다.
7. 새벽+활성5분 조건인 `mistaxolotl`은 첫5분 경계에서 낮으로 바뀌므로 최초 적격 시각은20분이다. 미도달이 버그인지 의도된 기대인지 도감 진행 설명으로 구분해야 한다. 자동으로 '5분이면 등장'이라 요약하지 않는다.

## 현재 결론과 후속 업데이트 조건

**현재 판정: 실제 기능 오류1건과 보상/방치/경제 실험 후보가 준비됨. 재미 통과 판정은 보류.** D1 표시 모순은 Electron에서 재현됐다. 다음 업데이트에서는 이 오류를 수정하고 E의 초과 포획 보류를 작은 실험으로 검토한다. 실제 발견이 눈에 띄고 다음 기대가 이해되는지도 A로 이어서 검증한다. 새 업데이트의 성공은 몬스터 종류 수·클릭 수·총 플레이시간 증가만으로 판단하지 않는다. 작업으로 돌아갈 수 있으면서 보상이 보존되고 다음 발견을 스스로 기다리는 행동을 확인해야 한다.

후속 실측이 오면 이 문서에 명령·코드 식별자·원시 근거 경로를 붙여 D1–D8을 확인/반증/미확인으로 갱신한다. 수치 결과만 받아 '재미있다'로 결론을 바꾸지 않는다.
