# v0.4 확정 스타일 영웅 50종

사용자가 승인한 **14×14 SD 크기, 원본 공격 자세, 후드·투구, 의상·무기 디테일,
피부와 눈 색상 차이**를 기준으로 50종을 제작해 실제 게임의 영웅 목록에 적용했다.
이전 32×32 외형을 교체하며, 확정한 검귀·자객·성기사 3종은 H01·H05·H09에 그대로 포함한다.

## 디자인과 구현

| 직업 계열 | 외형에서 구분되는 장비 |
| --- | --- |
| 검사 | 백발·머리띠·관자놀이 갑주, 교차깃, 검과 장식 손잡이 |
| 창술사 | 묶은 머리·장식 비녀, 전투복과 견갑, 창날·삼지창 |
| 거너 | 모자 챙과 코트 깃, 벨트, 권총 총신과 손잡이 |
| 성직자 | 두건·예식 모자, 스톨과 금장 예복, 십자 성물 |
| 도적 | 후드 앞챙과 테두리, 가죽 띠와 망토, 짧은 단검 |
| 광전사 | 거친 머리와 장갑, 가죽 하네스, 넓은 대검 |
| 마법사 | 낮은 고깔 모자, 로브 재단, 보석 지팡이 |
| 격투가 | 머리띠와 매듭, 도복과 허리띠, 너클 |
| 수호기사 | 투구 이마판·볼가드, 판금 예복·방패, 성검 |
| 소환사 | 베레와 두건, 케이프와 가슴 장식, 펼친 마도서 |

- 10직업 × 5등급, **50개 고유 실루엣**, 총 **250프레임**.
- 모든 외형은 14×14, 대기 2장·공격 3장. 등급이 올라가도 신체 크기와 도트 크기는 같다.
- 눈 위치, 양손의 공격 궤적, 발바닥 접지를 원본에서 유지했다. 후드·투구는 얼굴을 둘러싸며 눈을 가리지 않는다.
- 각 모습은 피부·눈동자·장비 색이 어울리는 7색 팔레트를 쓴다. 눈은 전용 역할 `i`의 1픽셀이고 장비 색을 공유한다.
- 팔·얼굴의 피부색은 모든 자세에서 일치한다. 피부와 눈의 명암 대비로 실제 표시 크기에서도 구분한다.
- 날개·후광·공중 장식을 붙이지 않으며, 장비 픽셀은 몸과 연결된다.
- 렌더러와 카드가 같은 `heroFormSprite`를 사용한다. 400×260 필드, 96px 환생 카드와 64px PvP 목록에서 영웅은 동일한 56×56px이고, 도트 하나는 4×4px이다.
- 검 계열에만 베기 효과를 표시하며, 효과와 머리 위 HUD를 원본 크기에 맞췄다.

도트 데이터는 `heroKnightLooks.ts`, `heroAgileLooks.ts`, `heroArcaneLooks.ts`에 나누고,
`heroLook.ts`에서 기존 대기 호흡을 공통 적용한다. `heroForms.ts`는 이 50종을 기존 ID 순서로 등록한다.
게임 그래픽은 모두 코드 데이터이며 PNG는 검토용 화면 캡처다.

## 저장 및 게임 동작

`h01`~`h50`의 ID·순서·등급·속성·버프 종류와 수치 규칙을 유지한다.
기존 장착 모습, 도감 수집, 환생 후보와 roll, PvP 업로드 데이터는 그대로 이어진다.
외형 변경 때문에 다시 추첨하거나 저장 형식을 변경하지 않는다.

[기존 호환성 검사](../../tests/heroArtCompatibility.test.ts)는 모든 ID를 각각 장착한
version 3 저장 파일을 불러와 재저장·엔진 복원·PvP 전송까지 수행하고,
후보·버프 수치가 보존되며 RNG가 호출되지 않는지 검증한다.

## 검증과 재현

```sh
npm test && npm run lint && npm run typecheck
npm run build
node .harness/v4/loop/render-heroes.mjs
node .harness/v4/loop/render-hero-scenes.mjs
```

단위 검사는 250프레임의 크기·팔레트·홍채·손·발·연결성,
50개 무채색 실루엣과 등급별 장비 차이를 검사한다.
실제 렌더러의 50종 대기·타격, PvP 반전, HUD·검격 위치도 검증한다.

2026-09-09 최종 검증: **44개 파일·676개 테스트**, 린트·타입 검사·빌드 모두 종료 코드 0.
최종 데이터 검사에서 50개 실루엣·250프레임, 서로 다른 피부색 50개·눈 색 50개를 확인했다.
피부와 눈의 최소 명암비는 3.02:1이며, 확정 3종의 대기·공격 데이터는 원본 시안과 정확히 일치한다.

브라우저에서는 실제 메뉴 바인더·CSS·엔진에 로컬 데이터만 주입해 크기와 동작을 확인한다.
[게임 화면 미리보기](hero-game-preview.html)는 검토용 로컬 fixture이며 운영 서버에 연결하지 않는다.
도감은 10열 × 5등급으로 표시되며 공격·정지·반전·확대를 지원하고 좁은 화면에서는 열 수가 줄어든다.

Electron 실행·패키징·운영 서버 배포는 이번 그래픽 작업 범위에서 수행하지 않았다.
