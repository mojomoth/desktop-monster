# DesMon 0.8 외부 관찰 기록지

대상은 새 macOS 사용자 5명이며, Apple Silicon Mac 2대 이상에서 설치·권한·실제 전역 입력·음소거를 확인한다. 현재 사람 관측 결과는 **미수집**이다. 자동 입력과 준비된 세이브의 성공을 자연 플레이나 리텐션으로 계산하지 않는다.

## 진행자 준비

ACCEPTANCE.md의 기술 검증 상태와 배포할 DMG의 SHA-256을 확인한다. 참가자에게 테스트 빌드임을 설명한다. 기존 DesMon 사용자는 개인 세이브를 보호하고, 신규 사용자 관찰과 구분한다. 이 빌드는 개발자 서명·공증을 포함하지 않는다. 설치가 macOS에서 차단되면 우회 성공으로 기록하지 말고 화면과 과정을 기록한다.

공유 범위는 앱 화면과 관찰 메모이다. 업무 화면, 입력 내용, 개인 파일, 인증 토큰을 수집하지 않는다. 입력 연결은 참가자가 직접 선택하고 macOS 권한을 직접 승인한다. 도움을 준 시점은 기록한다.

## 자연 관찰 — 90분

참가자가 실제 업무를 하며 사용하도록 한다. 처음에는 기능 설명이나 특정 행동을 유도하지 않는다. 첫 화면 이해, 창 입력 선택 또는 전체 입력 연결, 권한 처리, 첫 메뉴 방문, 자발적 도감 확인·영웅 선택·동료 관리 시각을 기록한다. 음소거와 화면 흔들림 설정을 찾는 과제는 자연 관측을 마친 뒤 진행한다.

## 준비된 상태의 이해 과제

자연 관찰이 끝난 뒤 테스트 전용 상태에서 수행한다. 참가자의 개인 세이브를 덮어쓰지 않는다. 환생 가능·희귀 후보·동료 30명의 상태를 각각 제시한다. 진행자는 정답을 미리 설명하지 않는다.

앞의 핵심 4개 과제 각각에서 최소 4/5명이 도움 없이 설명과 행동 찾기를 완료해야 한다. 같은 핵심 오해가 2명 이상이면 UI를 수정하고 해당 화면을 보지 않은 신규 참가자에게 다시 확인한다. 준비된 과제 성공률과 자연 획득률을 별도로 집계한다.

## 다음 업무일

예정된 테스트 재방문을 요구하지 않는다. 다음 업무일이 지난 뒤 자발적으로 다시 실행했는지와 그 이유를 묻는다. 재실행 시각·확인 방법·재실행/미실행 이유·사용 중단 이유를 기록한다. 예정된 세션, 진행자의 알림 후 실행, 진단용 재시작은 자발적 재실행에 포함하지 않는다.

## 결과 집계

모집·일정은 사용자가 진행한다. 이 파일은 빈 프로토콜이며 사용자 다섯 명의 실제 결과가 아니다. ACCEPTANCE.md에 참가자 수, 기기 수, 핵심 과제별 분모와 성공 수, 반복 오해, 수정 및 신규 재관찰, 다음 업무일 자발적 실행을 근거와 함께 기록한 뒤에만 `external_test_and_usability_complete`로 전환한다.
